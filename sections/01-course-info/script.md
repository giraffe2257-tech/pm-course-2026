# Section 01 — Course Overview 課程目標｜講師逐字稿

---

[切換投影片：Course Overview]

好，歡迎大家。我是今天的講師，接下來三個小時，我們要一起做一件很酷的事——你們會學會用 AI Agent 工具，把腦袋裡的想法，變成真的能跑的東西。

[停頓]

先聊一下，在座的各位是 Technology Management 的碩士生，對吧？所以你們對科技趨勢、專案管理、商業策略這些東西其實已經很熟了。但我猜，如果我現在說：「來，打開 terminal，我們寫一段程式」——有些人可能會開始冒冷汗。

[看向觀眾]

[互動] 誠實舉手——在座有多少人，從來沒有寫過程式，或者寫過但已經完全忘記了？

[停頓，等待舉手]

好，很好，手放下。不管你有沒有舉手，今天這堂課都是為你設計的。因為我要告訴你們一個 2026 年的現實：**你不需要會寫程式，你需要會指揮 AI 幫你寫程式。**

[切換投影片：課程對象]

我們先來對齊一下——你們是誰、我是誰、我們今天要幹嘛。

你們是 KCL Technology Management 的碩士生。你們的優勢是什麼？你們懂商業邏輯、懂使用者需求、懂怎麼把一個 idea 變成一個 project plan。這些能力，在 AI 時代反而變得更值錢了。為什麼？因為 AI 最缺的就是判斷力——什麼該做、什麼不該做、做出來的東西到底有沒有商業價值。這些 AI 不會幫你想，但你們會。

最近小紅書上有一篇很紅的文章，一個設計師分享她轉型做 AI 產品設計師的經歷。她說了一句話我覺得很精準——她之前碰到大模型、AI Agent 這些術語的時候，也是一頭霧水。但當她真正理解了這些工具能做什麼、不能做什麼之後，面試的時候就能展現出專業認知，最後拿到了理想的 offer。關鍵不是她學會了寫程式，而是她學會了**判斷**。

這就是今天的核心精神。

[切換投影片：教學原則 70/30]

所以我們今天的教學原則很簡單：**七成動手，三成講解。**

我不會花太多時間跟你們講理論。理論的部分，你們回去看 Anthropic Academy 的免費課程就好了——他們 2026 年上線了十三門課，全部免費還有證書，品質非常好，週末兩天就能刷完核心內容。今天我們要做的事情不一樣。

今天，每一個練習都是一個商業場景。不是「Hello World」那種無聊的東西，是你們未來工作中真的會碰到的情境。我要你們建立的能力是：**拿到一個需求，知道怎麼拆解它，然後用 Claude Code 把它做出來。**

[停頓]

換句話說，判斷力大於技術力。你不需要看懂每一行 code，但你要能判斷 AI 產出的東西對不對、好不好、夠不夠用。這個判斷力，才是你們作為 Technology Manager 的核心競爭力。

[切換投影片：課程時長與結構]

來，看一下今天的時間安排。我們總共三個小時，中間會有一次十分鐘的休息，讓你們上個廁所、回個訊息。整堂課分成八個段落，循序漸進——從最基本的「Claude Code 是什麼」，一路帶到你們能獨立完成一個小專案。

八個段落，每一個都會比前一個再進一步。所以如果前面有什麼沒完全跟上的，不用慌，後面還會反覆練到。

[看向觀眾]

[互動] 有一件事我要先跟你們約定好——等一下進入練習環節的時候，如果你卡住了，第一件事不是舉手找我，而是先問 Claude。認真的。因為這就是這個工具最強的地方：你遇到問題，直接用自然語言描述你的困境，它會幫你解決。如果 Claude 也搞不定，那再叫我，我很樂意過去。這個習慣很重要，因為回到工作崗位上，你不會有講師站在旁邊，但你永遠有 Claude。

Deal？

[停頓，等待觀眾回應]

好，那我們就開始。下一個段落，我們來認識一下今天的主角——Claude Code 到底是什麼、它跟你平常用的 ChatGPT 差在哪裡。
