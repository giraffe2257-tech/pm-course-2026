## 三層架構

[切換投影片 — 三層架構表格]

來，看這張表。AI 的世界其實有三個層級：

第一層，**LLM**，也就是模型本身。Claude Opus 4.6、GPT-4o、Gemini 2.5 Pro——這些是「大腦」。它們是原始的智能，很強大，但它們本身不是產品。你沒辦法直接去用一個模型，就像你沒辦法直接拿一顆引擎去上路一樣。

第二層，**Product**，產品。ChatGPT、Claude.ai、Gemini App——這些是把模型包裝起來，加上介面、加上使用體驗之後的成品。你平常開瀏覽器用的那個聊天視窗，就是這一層。

第三層，**Agent**，代理。Claude Code、Cursor、Windsurf——這些不只是讓你聊天，它們能自主行動、能讀寫你的檔案、能幫你執行程式。

[停頓]

[看向觀眾]

為什麼這個分層重要？因為以後你在公司開會，有人說「我們用 AI 來做這件事」，你要能問出一個精準的問題：「你說的 AI 是哪一層？」

買 LLM 的 API，是買原料。買 Product，是買現成工具。導入 Agent，是請了一個 AI 員工。三件事的成本、風險、能力範圍完全不同。

小紅書上有個用了半年 Cursor 和 Claude Code 的人，寫了一篇對比文章。他的結論很精準——Cursor 像副駕駛，你開車它幫你看路、幫你導航。Claude Code 像項目經理，你告訴它目的地在哪，它自己規劃路線、自己開過去。一個是人機交互循環，一個是全自動模式。這就是 Product 和 Agent 的差別。

## ChatGPT vs Claude Code 對比

[切換投影片 — 對比表格]

好，理論講完了，我們看具體差異。

我用你們最熟悉的 ChatGPT 來當對比。ChatGPT 是第二層——Product。Claude Code 是第三層——Agent。它們的差異在哪？

[逐行帶過表格]

**互動方式**——ChatGPT 是什麼？你複製東西貼給它，它回文字給你。就這樣。你是搬運工。而 Claude Code 呢？它直接讀你電腦裡的檔案，直接在你的電腦上跑程式。

**工作流程**——用 ChatGPT，你的流程是：複製、貼上、拿回覆、再複製回去。來來回回。而 Agent 的流程是：你告訴它要做什麼，它自己去找資料、改程式碼、跑測試。

**處理範圍**——ChatGPT 一次一段對話，context 有限。Claude Code 能看到你整個專案資料夾，數百個檔案同時處理。

**你的角色**——這是最關鍵的。用 ChatGPT 的時候，你是操作員，手動搬運每一步。用 Agent，你是管理者——你下指令、審核結果。

[停頓]

小紅書上有人總結了一個選 AI 工具的黃金標準——看這個工具能不能「進入你的日常工作流程」。很多工具你用一次覺得很酷，然後就再也沒打開過。為什麼？因為如果每次都要複製貼上、來回搬運，摩擦力太大了，你自然不會持續用。Agent 的價值就在這裡——它降低了摩擦力，讓 AI 真正「嵌入」你的工作方式。

還有人畫了一張 AI 能力進化路徑圖：Prompt → Skill → Agent。第一階段你只會問問題，第二階段你學會把常用的 prompt 變成可重複的技能，第三階段你讓 AI 自主完成整個流程。今天我們的目標就是帶你從第一階段跳到第三階段——你不需要中間慢慢爬，因為 Claude Code 直接把你放到 Agent 這一層。

## Demo 對比：分析 100 份問卷

[切換投影片 — Demo 對比]

來，我給你們一個具體場景。假設你今天碩論要分析 100 份問卷，你有一個 CSV 檔案。

### 用 ChatGPT 的流程

[切換投影片 — ChatGPT 流程]

你打開 CSV，複製前 50 行——因為有字數限制，你還不能一次全貼。貼到 ChatGPT 說「幫我分析」。然後它說「哦我只看到一半的資料」。好，你再貼後 50 行。

然後它給你一段 Python code。你看著那段 code 想——我要在哪裡跑？你 Google「怎麼跑 Python」，找了個線上環境，貼進去，跑出 error。

你把 error 複製，貼回 ChatGPT，它跟你道歉、改 code、你再跑……來回十次，圖表終於出來了。

然後你的指導教授說：「這個圖的顏色不好看，改一下。」

你又要再來一輪。

聽起來是不是很熟悉？

### 用 Claude Code 的流程

[切換投影片 — Claude Code 流程]

好，同樣的任務，用 Claude Code 怎麼做？

然後你看著它：讀取 CSV——全部 100 筆，不用分批。執行 pandas 統計分析。生成圖表。存到 charts/age_vs_adoption.png。

你指導教授說要改顏色？你再說一句：「改深色背景，字體放大。」

它改了，重新生成，結束。

## 核心觀念：從「對話」到「委派」

[切換投影片 — 從對話到委派]

我把這個差異用一句話總結：

用 ChatGPT，你是在「對話」——你問它答，一來一回。

用 Claude Code，你是在「委派」——你交代任務，它自己去執行。

[停頓]

流程是這樣的：你的想法，交給 AI Agent，Agent 去操作檔案系統、執行程式，直接產出完成品。

這不只是效率差異。這是工作模式的根本轉變——從「我操作工具」變成「我管理 AI 去操作工具」。

[停頓]

回到我們的身份——Technology Management。你們未來的職責就是管理技術資源。AI Agent 本質上就是一種新型的技術資源。你不需要自己去寫每一行程式，但你需要知道怎麼指揮它、怎麼審核它的產出、怎麼判斷它的結果對不對。

這跟管理一個工程團隊其實是同一種能力。差別只在於，你的「下屬」回應速度是秒級的，不用發 Slack 等半天。
