# Part 3 · 20 min — Setup & First Commands

每個人的電腦都要跑起來。

## Steps

1. **安裝**
   `npm install -g @anthropic-ai/claude-code`

2. **第一次對話**
   在空目錄啟動 `claude`，問一個簡單問題

3. **核心概念**
   Terminal-native AI：它能讀檔案、寫檔案、跑命令

4. **Permission Model**
   為什麼它會問「可以嗎？」——人類始終在控制迴圈中

## 練習 1

讓 Claude Code 幫你建一個 `index.html`，內容是你的自我介紹頁面。
