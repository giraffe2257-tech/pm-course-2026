# Part 6 · 15 min — AI Governance & Judgment

Technology Manager 必須思考的問題。

## 討論主題

### 1. 能力邊界

- Claude Code 能做什麼、不能做什麼？
- 現場測試邊界——故意給它做不到的事
- 理解 hallucination 的風險

### 2. 安全意識

- API keys 不要硬寫在 code 裡
- 生成的 code 要 review，不要盲信
- Permission model 存在的原因

### 3. 組織導入

- 誰該用？怎麼用？ROI 怎麼算？
- Code review 流程怎麼調整？
- IP / 資料安全政策

### 4. 成本結構

- ChatGPT 月費吃到飽 vs. Agent 按 API 用量計費
- 影響你的預算規劃
- 不同場景選不同工具
