# Part 4 · 25 min — 如何跟 AI 有效溝通

Technology Manager 最重要的 AI 技能——下指令。

## CCC 框架

1. **C — Context**
   背景：你在做什麼、為什麼

2. **C — Constraint**
   限制：技術棧、時間、範圍

3. **C — Criteria**
   標準：什麼叫「做好了」

## Prompt 對比

### Bad Prompt

> "Make me a website"

### Good Prompt

> "Build a responsive landing page for a SaaS product using HTML/Tailwind. Include hero section, 3 feature cards, and a CTA button. Mobile-first."

場景：「你的團隊需要一個內部工具追蹤 OKR」。用 CCC 框架寫出 prompt，讓 Claude Code 建出 MVP prototype。
