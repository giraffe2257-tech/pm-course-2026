# Hero — 開場講稿

---

[燈光亮起，講師站在投影幕前，螢幕顯示 Workshop 主視覺]

[看向觀眾，微笑]

大家好！歡迎來到今天的 Claude Code Workshop。

我先做個快速確認——大家都能看到螢幕對吧？後面的同學也看得到？好。

[停頓]

先自我介紹一下，我是今天的 facilitator。接下來三個小時，我們要一起做一件事：把 AI 從「聊天工具」變成你的「工作搭檔」。

[指向螢幕上的副標題]

我們的副標題寫的是 "From Chat to Command"。這什麼意思？我相信在座各位都用過 ChatGPT、用過 Claude，對吧？你打開瀏覽器，輸入一個問題，它給你一個回答。這是 Chat。

但今天我們要做的事情不一樣。我們要讓 AI 直接在你的電腦上幫你工作——讀你的檔案、幫你寫東西、幫你整理資料、幫你建立專案。這是 Command。

[停頓]

你可能會想：「等一下，這聽起來像是要寫程式？」

[看向觀眾]

不用。

[互動]

在場有多少人寫過程式的？舉個手讓我看看。

[等待]

好，有一些。那沒舉手的同學，恭喜你們，你們來對了。這個 Workshop 的設計原則就是——No Coding Required。你不需要會寫程式，你只需要會打字、會用英文跟 AI 講話就夠了。事實上，Claude Code 最厲害的地方就在於，它把 terminal 這個以前只有工程師才會用的東西，變成了任何人都能上手的 AI 工作介面。

[停頓]

而且我跟你們說，那些舉手說會寫程式的同學，今天可能會最驚訝。因為你們會發現，很多你以前花好幾個小時做的事情，現在幾分鐘就搞定了。

[切換投影片，顯示 Meta 資訊]

來，我們看一下今天的基本資訊。三個小時，Hands-on Workshop，也就是說——我講的時間其實不多，大部分時間是你們自己動手。我最多只佔三分之一的時間來講概念，剩下的時間你們會直接在自己的電腦上操作。

我一直覺得，學 AI 工具最沒用的方式就是坐在那邊看別人 demo，然後覺得「哇好厲害」，回去之後什麼都不記得。今天不會這樣。今天你會自己打開 terminal，自己跟 Claude 對話，自己完成任務。三個小時後走出這個教室，你就有實戰經驗了。

[停頓，語氣稍微認真]

最後在我們正式開始之前，我想跟大家分享一個觀點。

現在外面很多人在討論 AI 會不會取代人類的工作。但我覺得，對你們這些學 Technology Management 的人來說，真正重要的問題不是「AI 會不會取代我」，而是「我能不能成為那個指揮 AI 的人」。

今天的 AI 已經不只是回答問題的聊天機器人了。它已經變成一個可以執行任務的 agent——一個數位員工。而你們作為未來的科技管理者，要學的不是怎麼寫程式，而是怎麼管理這個新型態的「員工」。

這就是今天的核心：學會怎麼用自然語言，去指揮一個 AI agent 幫你完成真實的工作。

[看向觀眾，微笑]

好，準備好了嗎？

[互動]

我們就直接開始。

[切換投影片至下一段]
