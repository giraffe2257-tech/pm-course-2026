# Part 2 · 15 min — AI 的三個層級

理解 LLM、Product、Agent 的差異——你未來做採購決策時，要分清買的是什麼。

## 三層架構

| 層級              | 範例                                  |
|-------------------|---------------------------------------|
| LLM（模型）      | Claude Opus 4.6, GPT-4o, Gemini 2.5 Pro |
| Product（產品）   | ChatGPT, Claude.ai, Gemini App        |
| Agent（代理）     | Claude Code, Cursor, Windsurf         |

## ChatGPT vs Claude Code 對比

| 面向     | ChatGPT / Claude.ai                         | Claude Code / Cursor / Windsurf              |
|----------|----------------------------------------------|----------------------------------------------|
| 互動方式 | 貼東西給它，回文字給你                       | 直接讀寫電腦檔案、跑程式                     |
| 工作流程 | 複製 → 貼 → 拿回覆 → 複製回去               | 告訴它做什麼，自己找改測                     |
| 處理範圍 | 一次一段對話，上下文有限                     | 整個專案資料夾，數百檔案                     |
| 能做的事 | 回答問題、生成文字                           | 建檔案、執行程式、分析數據                   |
| 你的角色 | 操作員（手動搬運每一步）                     | 管理者（下指令、審核結果）                   |

## Demo 對比：分析 100 份問卷

### 用 ChatGPT

```
1. 打開 CSV，複製前 50 行（有字數限制）
2. 貼到 ChatGPT：「幫我分析」
3. 發現沒看到完整資料，再貼後 50 行...
4. 給你一段 Python code
5. 自己找地方跑，跑出錯
6. 複製 error 貼回去問...
7. 來回 10 次，圖表終於出來
8. 想改顏色？再來一輪...
```

### 用 Claude Code

```
你：「讀 survey.csv，跑 descriptive stats，
     做 cross-tab，輸出圖表到 charts/」

Claude Code：
  ✓ 讀取 survey.csv（全部 100 筆）
  ✓ 執行 pandas 統計分析
  ✓ 生成圖表
  ✓ 存到 charts/age_vs_adoption.png

你：「改深色背景，字體放大」
  ✓ 修改設定，重新生成
```

## 核心觀念：從「對話」到「委派」

你的想法 → **AI Agent** → 檔案系統 → 程式執行 → 完成品

> 這不只是效率差異，是工作模式的轉變——從「我操作工具」變成「我管理 AI 去操作工具」。
