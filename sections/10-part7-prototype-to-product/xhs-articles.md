## 文章 1：拒绝加班！AI1分钟画好产品原型，PM救星✨

### 內容

步骤 1：获取开源项目
打开 GitHub 首页，搜索 “cursor talk to figma mcp”。
点击搜索结果中的项目，进入项目主页。
点击 “Code” 按钮，下载项目的压缩文件。
	
步骤 2：安装必要的环境
打开 终端（Terminal）。
在 GitHub 项目描述中找到启动命令行，按顺序输入到终端。
复制并运行第一个命令，安装 Bun（JS 运行时环境，后续步骤会依赖它的功能）
	
步骤 3：进入项目目录
输入 cd （加空格），然后将刚刚下载的项目文件夹拖入终端，按回车执行。
这样就完成了 切换到项目的工作目录。
	
步骤 4：安装 MCP
复制 GitHub 项目中的 第二行命令，在终端中运行。
这一步会 安装 MCP 并将其集成到 Cursor 当前打开的项目中。
	
步骤 5：启动服务器
复制 第三行命令，在终端中运行。
这一步会 启动一个允许双向实时通信的服务器，用于连接 Cursor 和 Figma。
	
步骤 6：在 Cursor 配置 MCP
打开 Cursor，点击 “设置”。
进入 MCP 设置，点击 添加新的 MCP 全局服务器。
返回 GitHub 项目，复制提供的服务器地址，将其粘贴到 Cursor MCP 设置中，完成配置。
	
步骤 7：在 Figma 安装插件
打开 Figma，进入 插件管理：
点击 菜单 → 插件 → 开发 → 导入插件。
找到刚刚下载的 GitHub 项目文件，安装插件。
安装完成后，运行插件，等待连接成功，这时会显示一个 Channel 代码。
	
步骤 8：连接 Cursor 和 Figma
返回 Cursor，打开一个项目。
在对话框中输入 “talk to figma” 并发送。
Cursor 会要求输入 Channel，复制刚刚在 Figma 插件中的 Channel，并粘贴到 Cursor 对话框，发送即可完成连接。
	
步骤 9：使用 Cursor 生成 Figma 设计
在 Cursor 输入你的需求，例如：“帮我画一个移动端的登录页面”。
观察 Figma 自动根据 Cursor 指令绘制高保真原型。
