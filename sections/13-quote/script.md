# Closing Quote — 講稿

[切換投影片 — 畫面只有一句話：「你不需要會寫 code，但你需要會指揮 AI 寫 code。」]

[停頓三秒，讓觀眾讀完]

好，我想用這句話，作為今天整個 workshop 的結尾。

[看向觀眾]

回想一下，兩個小時前你們走進這間教室的時候，有多少人心裡想的是：「我又不是 CS 背景，這跟我有什麼關係？」

[停頓]

但你們剛剛做了什麼？你們用自然語言，讓 AI 幫你建了一個完整的產品 prototype。你沒有寫任何一行 code——但你做了所有關鍵的決策。你決定了產品要解決什麼問題、用戶是誰、流程怎麼走、介面長什麼樣。

這就是「指揮」的意思。

[停頓]

我很喜歡一個說法——在 AI 時代，真正不可替代的能力，不是你能不能寫出演算法，而是你有沒有批判思維、有沒有價值判斷、有沒有能力把一個模糊的商業問題，拆解成 AI 能執行的具體指令。

這些東西，恰好就是你們在 Technology Management 這個program 裡每天在練的。

[看向觀眾]

所以我今天想留給大家的 takeaway 很簡單——

你們已經具備了最難的那一半：理解商業、理解用戶、理解策略。今天我們補上的，只是另一半的入口：怎麼把這些思考，透過 AI 變成可以跑的東西。

[停頓]

從今天開始，當你有一個 idea 的時候，你的第一反應不再是「我需要找一個工程師」，而是「讓我先打開 Claude Code 試試看」。也許十分鐘之後，你就有一個 working prototype 可以拿去跟人討論了。

這個改變，比學會任何一個程式語言都重要。

[停頓，語氣放輕]

好，這就是今天的全部內容。投影片、所有的 prompt template、還有今天提到的資源連結，我都會放在課程頁面上。

[互動] 有沒有最後的問題？任何問題都可以——關於工具的、關於怎麼應用到你們自己 project 的，都歡迎。

[等待回應，回答問題後]

好，謝謝大家今天的參與。去 build something cool 吧。

[結束]
