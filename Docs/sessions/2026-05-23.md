### 關鍵決策
- **Cursor 代勞安裝(取代 git clone 教學)** — 第一次 workshop 學員無預習能力,Cursor AI 自動安裝 Node.js / Claude Code / API key 比講師救火更省力;且 setup 過程本身就是 AI Agent 的隱性 demo
- **Part 6 刪除** — Governance 內容對 3 小時 workshop 來說太重,壓縮其他 Part 不划算;日後可加回
- **Part 4 練習改 demo** — 學員此時還沒實作經驗,讓他們改寫只會卡住,改成講師投影直接展示三個對應 Part 5 場景的範例
- **CLAUDE.md 範例用 Dissertation 場景** — 比 workshop 自身的 meta CLAUDE.md 更有「可代入感」,學員能想像「我的論文資料夾應該長這樣」
- **設計第二次重做轉 Apple HIG** — 第一次 Editorial 風格雖然有特色但太重;Apple HIG 對非 CS 學員更友善(熟悉的視覺語彙、清晰層級、Mac 上原生字體渲染)
- **第三層保險:USB / AirDrop 備援** — 不依賴單一交付管道,setup.md 可以 GitHub raw / AirDrop / USB 三種方式給學員
